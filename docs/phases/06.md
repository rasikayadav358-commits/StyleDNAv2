# Phase 6 — Catalog, web suggestion engine, and gap analysis [P0 local, P1 live]

**Provider interface:** ProductProvider.search(...)

- LocalCatalogProvider: seeded catalog in INR with realistic products and pgvector ANN retrieval.
- LiveSearchProvider: permitted API with timeout, circuit breaker, and graceful fallback to local provider.
- Similar-to-item: GET /suggestions/similar?item_id=
- Gap analysis: test virtual archetypes, count new valid outfits added by occasion, and rank by utility.

**API:** GET /gaps, GET /suggestions, GET /suggestions/similar, GET /trends, POST /wishlist, GET /wishlist, DELETE /wishlist/{id}.

**Acceptance:** suggestions return ranked local products with budget respected and honest source labels; timeout fallback works in under 4 seconds; gap analysis is deterministic across repeated runs.
