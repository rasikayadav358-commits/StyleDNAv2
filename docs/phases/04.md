# Phase 4 — Body analysis [P0 manual path, P1 photo/video path]

**Manual path (P0):** user enters measurements; shape.py classifies soft rules from body_rules.yaml and returns shape + confidence + runner-up. Measurements are encrypted at rest.

**Photo/video path (P1):** MediaPipe Pose, segmentation, and silhouette ratios; validation errors for cropped/side/multi-person images; manual values win if present. Always show editable styling guidance, never a judgment.

**Output contract:** {shape, confidence, ratios, recommended_silhouettes[], suggested_fits[], styles_to_try[], notes} from body_rules.yaml, neutral and body-positive.

**Acceptance:** unit tests for canonical measurement sets; boundary cases return lower confidence; raw body media is deleted after analysis unless the user opted to keep it.
