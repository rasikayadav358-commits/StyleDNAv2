# Phase 1 — Auth & security baseline [P0]

**Deliverables**
- Registration/login/logout/refresh/me with argon2id hashing, minimum length 10, common-password list checks, constant-time compare, and generic errors.
- Access token JWT and rotating refresh-token cookie with family reuse detection.
- Rate limiting (Redis), security middleware, request-size limits, trusted hosts, CSRF protection.
- Authorization via get_current_user and ownership checks on every query.
- Consent model + audit log and docs/THREAT_MODEL.md.

**Acceptance:** login brute-force gets throttled; refresh-token reuse revokes family; user A cannot read/modify/delete user B's data; responses never include password_hash; security headers present; JWT with bad signature/expired/alg=none is rejected.
