# Phase 3 — Wardrobe AI [P0]

**Pipeline per wardrobe image**
1. Cutout, embedding, and attribute cascade via local zero-shot classification, learned head, and Claude vision fallback under consent.
2. Persist attributes with attrs_source and attrs_confidence; infer formality and default occasions/seasons from category-taxonomy rules.

**API:** POST /wardrobe/items, GET /wardrobe/items, GET/PATCH/DELETE /wardrobe/items/{id}, POST /wardrobe/items/{id}/worn, POST /wardrobe/video/{media_id}/candidates, GET /wardrobe/summary.

**Learning hook:** every PATCH that changes ML-predicted fields writes item_label_corrections.

**Acceptance:** offline flow works with local classifier + mock embedding; off-schema LLM output is rejected; corrections are logged.
