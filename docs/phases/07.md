# Phase 7 — The learning system [P0 simple loop, P1 full]

Goal: recommendations improve with feedback, safely, with offline evaluation and rollback.

**7.1 Event logging:** impression, like, dislike, save, skip, wear, variation, buy_click; append-only.
**7.2 Style DNA:** EMA update to user_style_state.style_vector and tag affinities from user events.
**7.3 Learned ranker:** rule score blended with model score; logistic regression early, LightGBM LambdaRank later; feature set includes rule components, body-fit, style, occasion, novelty, recency, etc.
**7.4 Exploration:** epsilon-greedy / Thompson sampling slot with logged propensity.
**7.5 Retraining & model registry:** train, evaluate, champion/challenger gating, rollback.
**7.6 Explainability:** feature contributions rendered as reasons.
**7.7 Admin/metrics:** GET /admin/ml/metrics.

**Acceptance:** bootstrap synthetic data and train/eval scripts run offline; learning-curve simulation shows improvement; challenger-gating prevents bad model promotions.
