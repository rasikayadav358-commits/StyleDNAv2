# Phase 2 — Secure media pipeline [P0]

**Storage**
- Private buckets; object keys = u/{user_id}/{kind}/{uuid4}; server-side encryption; envelope encryption for body-media assets.
- Delivery: wardrobe via presigned GET; body media via authenticated decrypted stream with Cache-Control: no-store.

**Upload endpoint (POST /media)**
- Validate by magic bytes, size/dimension limits, bomb protection, metadata cleanup, video validation.
- Face privacy: blur face by default for body media; raw body media is purged after analysis unless opted in.
- State machine: pending → processing → ready|rejected; Arq worker handles processing.

**Deletion:** DELETE /media/{id}, DELETE /me purges all user-owned objects and tokens; export via GET /me/export.

**Acceptance:** valid jpegs/png/mp4 pass; renamed .exe files fail; EXIF is stripped; 50k×50k PNG bomb fails; user B cannot fetch user A's asset; body asset bytes remain encrypted.
