# Phase 8 — Frontend [P0]

Mobile-first, accessible, friendly to users with no fashion knowledge. Typed API client generated from the OpenAPI schema.

**Screens:** landing, consent, style profile, body, wardrobe, create outfits, gaps & shop, trends, saved looks, settings/privacy.

**Rules:** no tokens in localStorage; no dangerouslySetInnerHTML; sanitize rendered text; offline-friendly fallbacks; optimistic UI for likes/saves.

**Acceptance:** full-journey Playwright smoke test passes; Lighthouse a11y ≥ 90 on main screens; no secrets or tokens remain in browser storage.
